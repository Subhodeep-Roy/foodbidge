## Agent Constitution

All agent decisions in this repository are governed by the strict rules defined in [`constitution.md`](file:///c:/foodbridge/constitution.md). The key principles are:
1. **Food Safety First**
2. **Time Sensitivity**
3. **Proximity Preference**
4. **Demand Alignment**
5. **Capacity Limits**
6. **Full Decision Transparency**
7. **Human Administrator Override**
8. **No Fabricated Information**
9. **Data Privacy**
10. **Auditability**
